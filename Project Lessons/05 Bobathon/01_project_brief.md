# Bobathon

With so many ingredients and options, customizing a boba drink can feel overwhelming. Our solution? **A drink builder that helps customers create a custom order one decision at a time.**

```card
{
title: In this project, you will
color: #fff8bf
}
- Listen to, consider the needs of, and design for a client
- Learn the following concepts:
    - Progressive disclosure
    - Admin analytics
- Build a full-stack drink builder with ingredients, toppings, summaries, and saved order codes.
- Store menu options and orders in Neon
- Test your site like a real customer and keep track of every change you make.
- Apply the project concepts to create a drink builder that guides customers and helps staff understand orders.
```
