# Project Planner

Keeping track of group projects is hard. Our solution? **A shared project workspace where groups organize responsibilities, tasks, deadlines, and progress.**

```card
{
title: In this project, you will
color: #fff8bf
}
- Listen to, consider the needs of, and design for a client
- Learn the following concepts:
    - User permissions
    - Chat systems
- Build a full-stack workspace where groups organize projects, assign tasks, and discuss their work.
- Store group membership, tasks, roles, and messages in Neon.
- Test your site like a real team member and keep track of every change you make.
- Apply the concepts to create a shared planner that keeps responsibilities and progress clear.
```

By the end of this project, you will have made a shared planner that keeps responsibilities and progress clear. **Let's get started!**
