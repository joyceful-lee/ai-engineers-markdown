# Plan It

Your answers to these questions will be used to create a build prompt for AI.

- What is the goal of the website?
- Who are you building for, and what do they care about?
- Describe how a user should use the website from the moment they visit it. What should they see first, what should they click, and what should happen next?
- What does a user do if they want to add a recipe, and what information do they enter?
- What preferences can a user enter to get recipe recommendations, and how should the site explain each suggestion?
- What does a user do if they want to like a recipe or leave a comment?
