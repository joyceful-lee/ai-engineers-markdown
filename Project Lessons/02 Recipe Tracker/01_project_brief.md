# Recipe Tracker

Deciding what to make for dinner is hard. Our solution? **Make a website where people can save and share recipes and get recommendations for what to cook.**

```card
{
title: In this project, you will
color: #fff8bf
}
- Listen to, consider the needs of, and design for a client
- Learn the following concepts:
    - Recommendation systems
    - External API integration
- Build a full-stack site where users create recipes, discuss meals, and find something to cook.
- Store recipes and account data in Neon and uploaded images in Vercel Blob.
- Test your site like a real cook and keep track of every change you make.
- Apply the project concepts to create a recipe community that helps people decide what to cook.
```
