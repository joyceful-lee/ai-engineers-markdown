# Treasure Expedition

Learning is more engaging when each exercise leads to visual progress. Our solution? **A map-based website where players complete challenges, build a collection, and return to continue exploring.**

```card
{
title: In this project, you will
color: #fff8bf
}
- Listen to, consider the needs of, and design for a client
- Learn the following concepts:
    - Gamification
    - Completionism
    - Trading
- Build a full-stack map with locations and challenges.
- Store player progress in Neon
- Test your site like a real explorer and keep track of every change you make.
- Apply the project concepts to create an expedition to help students learn.
```
