## Meet Your Client

**Noah has trouble reviewing for math class.** He knows he needs to study, but wants to play his favorite games instead. **What do we do?**

```talker
{
name: Noah
bubble: speech

I love level-based games because I like seeing my progress.
```

We can make a level-based educational adventure where players complete challenges to unlock new locations! Each solved challenge should open a path to a new location, helping Noah see his progression through the site.

This is **gamification.** Gamification uses game elements to make learning more engaging. For our site, we can turn math practice into an adventure!

## Your Goal

Build **Treasure Expedition**, where level-based challenges and visible progress make review more engaging.

Use GitHub to upload your code, Neon for authentication and database storage, and Vercel for deployment.

```checkbox
{

- Let players sign up, log in, and log out.
- Show a map or world with connected locations or levels.
- Give each checkpoint an educational challenge that builds in difficulty of topic.
- Clearly mark checkpoints as locked, available, attempted, or completed.
- Unlock the next checkpoint when its challenge is solved.
- Save completed checkpoints, attempts, scores, and times so players can continue in later sessions.
```
