# Submit It

## Grading Rubric

Before you submit, grade yourself using these questions.

- **If your answer to any of these is "no", then your project isn't ready.**
- Your instructor will use the same grading rubric when they look at your project.
- Select a question to see an example of what it means.

```checkbox
{
title: Function
color: #e7f7dc
}
- Can signed-in users create, edit, and delete binders?
- Can users add, edit, and remove cards in their binders?
- Can owners choose whether a binder is public or private?
- Can signed-in users like and subscribe to public binders?
- Can a visitor start collecting without creating an account?
- Does guest progress survive a page refresh, with its limitations clearly explained?
- Does signing in preserve the guest's work and return them to what they were doing?
```

```checkbox
{
title: Frequent Design Mistakes
color: #e7f7dc
example: What this mistake looks like
}
- Does the project NOT use any staccato language?
  > Staccato language strings short, punchy fragments together like a slogan, such as "Simple Flow. Clear Steps. Zero Confusion." Write in full sentences that flow instead.
  > **Before**
  ![Headings written as punchy fragments](public/course-assets/website-builder-course/modules/02_real_product_design/deadly-sins/staccato.png)
  > **After**
  ![The same section rewritten in plain sentences](public/course-assets/website-builder-course/modules/02_real_product_design/deadly-sins/staccato-fixed.png)
- Does the project NOT try to advertise itself to the user?
  > A site that advertises itself adds sections about why it's great or how it works. Anyone reading the site is already using it, so skip the pitch.
  ![A "How It Works" section pitching the site to its own visitors](public/course-assets/website-builder-course/modules/02_real_product_design/deadly-sins/advertising.png)
- Does the project NOT include Brandon's name in any way, shape, or form?
  > Background you give the AI, like who the site is for or why they need it, often ends up on the page. Visitors should never see the client's name or the story behind the project.
  > **Before**
  ![A hero that mentions the client by name](public/course-assets/website-builder-course/modules/02_real_product_design/deadly-sins/literally.png)
  > **After**
  ![The same hero with the client details removed](public/course-assets/website-builder-course/modules/02_real_product_design/deadly-sins/literally-fixed.png)
- Does the project explain only what it needs to without frequent signposting?
  > Signposting is text that tells people what to do next, like "Scroll down to learn more" or "Click the button below to get started." A little is fine, but good UI makes the next step obvious without explaining it.
- Does the project NOT use any generic fonts such as Arial, Calibri, etc.?
  > Left alone, AI tends to use fonts like Arial, Helvetica, Inter, or the system default. Pick a distinctive heading font and a readable body font from Google Fonts.
  > **Before**
  ![A menu set in a default system font](public/course-assets/website-builder-course/modules/02_real_product_design/deadly-sins/fonts.png)
  > **After**
  ![The same menu using Google Fonts](public/course-assets/website-builder-course/modules/02_real_product_design/deadly-sins/fonts-fixed.png)
- Does the project NOT use any emojis whatsoever?
  > AI often uses emojis as stand-ins for pictures and icons. Use real images, or an icon library like Google Icons, instead.
  > **Before**
  ![Menu items using emojis as pictures](public/course-assets/website-builder-course/modules/02_real_product_design/deadly-sins/emoji_1.png)
  > **After**
  ![The same menu items using real photos](public/course-assets/website-builder-course/modules/02_real_product_design/deadly-sins/emoji_1fixed.png)
- Does the project NOT look like a basic startup project?
  > The startup look combines dark mode, purple or blue neon gradients, and glassy cards. It rarely fits the audience, so choose colors and styles that suit who the site is actually for.
  > **Before**
  ![A dark, neon, startup-style hero](public/course-assets/website-builder-course/modules/02_real_product_design/deadly-sins/startup.png)
  > **After**
  ![The same hero with a warmer, lighter style](public/course-assets/website-builder-course/modules/02_real_product_design/deadly-sins/startup-fixed.png)
```
